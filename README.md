# Sudoku Solver Backtracking Algorithm Python

This example demonstrates the backtracking algorithm by solving a Sudoku puzzle. It recursively attempts to place numbers into empty cells, validating each placement. If a number leads to a dead end, the algorithm backtracks to the previous decision point and tries an alternative.

## Language

`python`

## How to Run

Save the code as `main.py`. Run from your terminal using `python main.py`.
